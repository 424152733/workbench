# 工作台按钮视觉规范调整

## 变更

- 工作台 Ant Design 默认按钮统一使用 `color="primary"` 与 `variant="outlined"`；带可见文字的普通按钮采用描边样式，纯图标按钮使用无边框的 `text` 样式。
- 带文字的取消、删除、解除关联、移出成员等有撤销或破坏性影响的操作使用 `color="danger"` 与 `variant="outlined"`；纯图标操作使用危险色 `text` 样式，不显示边框。
- Modal 与 Popconfirm 的取消按钮及破坏性确认按钮也按相同规范设置，包括动态的“确认取消”操作。
- 主题级关闭默认、主色和危险色按钮的底部阴影，保持描边按钮边缘干净。
- 描边按钮保留 Ant Design 默认的 hover 与 focus 状态；页面级样式不再用高优先级规则覆盖推荐选题和图文预览按钮的 hover 色。
- 相邻操作按钮使用一致尺寸；家庭关系行的“编辑”和“解除”统一为小号按钮。
- 一组并排的文字按钮使用相同尺寸，避免同一操作区的高度和留白不一致。表格行、卡片操作区、工具栏等紧凑区域可整组使用 `size="small"`；按钮优先级通过主色实心、描边或危险色表达。页面样式只给常规按钮设置固定高度，保留 Ant Design 小号按钮的原生高度。
- “新增客户”圆形悬浮按钮放在应用全局布局中，工作台所有页面均可打开同一新增客户弹窗。

## 2026-10-18 尺寸微调

- 客户列表、保单服务、家庭规划、首页卡片、发布记录、产品中心和内容编辑器中的次级操作改用小号按钮；并排操作组统一了尺寸，主次仍通过颜色和填充表达。
- 修正产品中心资料操作、家庭操作组、客户详情操作组、内容页标题操作组、生成操作组和编辑器底部操作组中的尺寸混用；更新按钮高度样式，避免页面 CSS 覆盖 Ant Design 的 `small` 尺寸。
- `npm run build` 通过；Chrome 当前 `/products` 页面可访问，已确认产品中心控件正常渲染。浏览器快照不提供像素级尺寸信息，具体视觉手感可直接在当前页面查看。
- 后续复核发现多个并排按钮组仍有常规与小号混用。本轮已统一这些按钮组；`/clients/1` 页面浏览器快照确认“加入已有家庭”和“建立家庭”均已更新并正常显示，构建通过。
- 产品目录卡片标题旁的“新建产品”改为小号实心按钮，让按钮高度贴合卡片标题行。
- 产品中心卡片标题区的左右内边距与内容区统一，目录标题和“新建产品”按钮的边缘对齐下方搜索框；窄屏下也与内容区保持一致。

## 覆盖范围

首页、客户与保单、客户详情、家庭规划、大话保险、产品中心，以及这些页面使用的弹窗和确认框。
