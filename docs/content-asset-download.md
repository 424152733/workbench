# 图文预览素材打包下载

## 功能

图文预览卡片右上角的下载图标会将当前选题、当前平台展示的全部配图打包成一个 ZIP 文件。按钮提示会显示平台名称和图片数量；打包期间按钮显示加载状态，完成后提示已下载的图片数量。图库和单张大图预览中的“下载”入口仍可单独下载一张图片。

压缩包在浏览器端生成，不增加后端接口或第三方依赖。ZIP 使用 UTF-8 文件名并保留素材原文件名；重名文件会自动增加序号，避免互相覆盖。图片请求失败时整包操作会报错，不会下载缺图的压缩包。

## 验证

- `npm run test:ui-logic` 覆盖 UTF-8 文件名、重名处理、图片字节完整性、ZIP 目录结构和空素材错误。
- `npm run build` 检查生产构建。
- ZIP 样例也使用 Python 标准库 `zipfile` 验证过文件名、内容和 CRC。
