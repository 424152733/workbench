# 家庭保单缺口初筛实施说明

**日期：** 2026-10-18  
**范围：** 家庭保单资料的规则式初筛；不含资产估值、现金流、投资持仓、风险评分、投保方案或自动投保建议。

## 实施范围

- 家庭详情新增“家庭保单初筛”，汇总家庭成员医疗、重疾、寿险、意外四类个人保障记录。
- 仅把明确关联为“被保险人”的成员计入个人保障分类；单独作为投保人的成员不会被误认为本人享有保障。
- 保障分类读取家庭保单已有分类标签。只有资料已核实、合同状态为有效，且起保/到期日期没有显示当前无效的记录，才计入“已核实记录”。
- 未关联被保险人、没有保障分类、尚未核实或不能确认当前有效的保单会作为资料提醒展示。到期、终止、暂停等记录不会计入当前保障；如有对应分类，会显示为非在保记录。
- 家财险和车险不与个人保障混算；页面提示这类保单需结合已登记投保对象单独核对。
- 初筛由本地规则计算，不调用语言模型、图片模型或外部服务，不增加数据库字段或 API。

## 展示边界

“档案暂无记录”只表示当前家庭档案中没有找到被保险人关联及对应分类，不能据此认定家庭成员实际没有投保。初筛也不判断保额是否充足、责任是否覆盖或产品是否适合。需对照正式合同核实；后续接入资产、现金流和投资信息后，才能扩展为更完整的家庭保障分析。
