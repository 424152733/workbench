# 工作行事历第一版

## 本版范围

- 新增独立的“工作行事历”页面，采用月历网格展示，不改变现有内容日历和客户跟进待办。
- 支持新增、编辑单场事件；事件可跨日期、填写可选起止时间和备注。
- 支持计划中、进行中、已完成、已取消四种状态。取消保留为记录，状态修改会更新最近修改时间。
- 支持每周重复。系统按周生成独立场次，最多 53 场；每场可以分别修改状态和内容。
- 首版事件不关联客户档案。需要针对特定客户开展的回访仍使用现有客户跟进待办。

## 数据与接口

- 新表 `work_calendar_events` 保存事件、状态、日期、重复系列编号和备注。
- `GET /api/work-calendar/events?month=YYYY-MM` 查询与月份相交的事件。
- `POST /api/work-calendar/events` 新建一次性事件或每周重复场次。
- `PATCH /api/work-calendar/events/:eventId` 编辑事件或更新状态。
- 新表通过 `014_work_calendar.sql` 迁移创建，不在启动 SQL 中写入演示事件。

## 当前边界

- 重复事件按独立场次保存；编辑或更改状态只影响当前场次，不会批量改动整个系列。
- 当前保存最新状态，不单独保留完整状态变更时间线。
- 首版不提供拖拽排期、客户关联、协作者和月度目标统计。
