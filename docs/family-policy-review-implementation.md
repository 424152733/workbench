# 家庭保单整理与保障检视首版实施记录

## 已实现

- 家庭页面可关联已有保单或成员客户档案中的 PDF，可为合同分别指定投保成员和被保险成员。新增 PDF 仍按现有本地解析流程处理，不自动调用付费 AI。
- 家庭检视按被保险成员展示重疾、身故、意外、住院医疗、津贴和长期资金责任。点击矩阵单元格可查看来源合同、责任条款、金额及页码。
- 归档保单与原 PDF 以保单 ID 去重；未归档 PDF 以合同 ID 计。合同归档时同步建立家庭保单关联。家庭来源提供“取消关联”，一次移除对应的家庭保单与全部已关联 PDF 链接，保留客户原始保单和合同；旧版保单解绑接口也复用相同操作。删除原合同或客户保单后仍遵循既有级联和排除规则。
- 个人保单删除时，先清理其原 PDF 的家庭链接再排除合同；家庭保单修改投保人或被保险人时同步更新已关联 PDF 的成员归属。关联多份 PDF 时，家庭检视优先读取当前家庭实际关联的合同。
- 家庭页面通过既有服务操作完成合同状态和日期变更后会重新读取家庭资料与检视，避免卡片仍显示修改前的状态。
- 已确认金额只包含人工核实、合同当前有效、被保险人明确且非多人共用限额的责任。多人共用限额保留为待核对参考金额；长期资金和住院津贴的给付口径不同，不合并成一个金额。身故与意外身故可能来自同一责任，页面明确提示不能相加。
- 家庭责任资料记录主要收入承担者、经济依赖成员、负债状态和长期目标。简要成员可补医保及单位补充医疗资料。服务重点先核对医疗，再按家庭收入责任看身故兜底，并考虑长期现金流；可打开现有跟进待办编辑弹窗。
- 家庭 Excel 复用个人版的“家庭保单整理”“保障责任明细”两张工作表及同一字段提取、金额分类和责任摘要规则。家庭成员行动态增长；只导出当前家庭关联的来源，同一保单与 PDF 不重复。多人共用限额或归属未确认的合同保留在明细中，不错误计入某一个人的金额。
- 两种 Excel 的成员概览金额现共用“资料已核实且合同确认有效”的判断，与家庭检视的有效金额口径一致；待核实或未确认合同仍在下方保单和责任明细展示，概览单元格注明未计入原因。

## 数据边界

- 家庭合同归属和人员角色使用迁移 `019_family_policy_review.sql` 中的表，以家庭成员 ID 关联，避免同名成员误归属。
- 已识别年交保费只汇总当前有效保单中明确写为“每年/年交/年缴”的保费，不能据此断定合同仍需续缴或由谁支付；界面标为“续缴待核”。
- 未确认的合同、过期合同、人数共用限额及缺少责任口径的金额不伪装成已确认保障。增额寿基本保额不等于现金价值，年金领取也不等于当前保障金额。
- 家庭服务重点是待核对事项，不是购买建议或最终理赔结论。正式保障范围以合同和保险公司确认资料为准。
