# 保单全周期与服务事项实施及测试报告

**日期：** 2026-10-16  
**范围：** `workbench/` 内客户与保单、首页提醒、数据库迁移

## 已实现

- 保单档案分别显示资料核实状态、合同状态、起保日、到期日及下次缴费日。合同状态由代理人核对后手动更新，保留依据、确认日期和变更历史；过了到期日只显示核对提示。
- 保单服务事项支持缴费、续保、保全、理赔咨询和其他类型；可新建、调整、记录进展、完成或取消。事项状态、下一步日期、结案结果和操作事件单独留存。
- 服务事项可关联客户联系待办与实际沟通。完成联系不自动结案；结案不自动改合同状态。续保新合同可手动关联原保单。
- 客户页新增“保单服务”视图，地址为 `/clients?view=services`；保单卡片、首页提醒可进入事项。首页和通知聚合当日及逾期事项，避免和同日关联待办重复提醒。
- 新增版本化迁移及外键级联规则。迁移只增加结构，不回填推断的合同状态或自动生成服务事项。独立预览端口可用 `WORKBENCH_LOCAL_FRONTEND_PORT` 显式放行本机来源。
